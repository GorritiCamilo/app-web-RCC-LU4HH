# app-web-RCC-LU4HH

Aplicacion frontend inspirada en la app mostrada en el manual `ManualCW_6820231035.pdf`, orientada al entrenamiento de telegrafia CW para el curso del Radio Club Cordoba LU4HH.

## Uso

Abrir [index.html](/Users/matiask/Documents/programacion/app-web-RCC-LU4HH/index.html) en un navegador moderno.

## Incluye

- Pantalla principal estilo app movil.
- Pantalla de ajustes con modales y opciones similares al manual.
- Sesion de practica CW con audio generado en el navegador.
- Perfil con estadisticas persistidas en `localStorage`.
